# 🎬 Cinema Booking Platform – Backend API

A backend API for a cinema booking platform (similar to BookMyShow / PVR) built using **Node.js, Express.js, and SQLite**.  
This project focuses on **core booking flows**, clean architecture, and practical backend design.

---

## 🚀 Features

### Authentication

- User registration
- User login using JWT

### Movies & Shows

- List movies
- List theaters by city
- List shows for a movie
- View seat layout & availability

### Seat Booking

- Create booking
- Prevent double booking
- View booking history
- View booking details
- Cancel booking

### Food & Beverage

- View F&B menu
- Add food items to a booking

### Payments (Simulated)

- Initiate payment
- Calculate ticket + F&B + GST + convenience fee
- Confirm payment

---

## 🛠 Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: SQLite
- **Authentication**: JWT
- **API Testing**: Postman

---

## How to run

- npm install
- npm run dev
